# Contributing to Cloudveil

Thank you for helping improve **Cloudveil: Path of Longevity**.
感谢你参与《长生渡》的开发。

## Ways to contribute

- Report reproducible bugs with browser, viewport size, and steps.
- Suggest new cultivation systems, events, companions, or accessibility improvements.
- Submit focused pull requests with a clear description.
- Improve documentation or translations.

## Development workflow

1. Fork the repository and create a branch such as `feature/spirit-beasts`.
2. Keep the project dependency-free unless a dependency is clearly justified.
3. Test both desktop and mobile layouts in a current Chromium or Firefox browser.
4. Verify local saving, breakthrough, battle, sect, companion, and alchemy flows when they are affected.
5. Open a pull request describing the change and how it was tested.

## Content guidelines

- Keep world-building, dialogue, names, and art original.
- Do not copy protected text or distinctive settings from published novels, games, or films.
- Use xianxia concepts as general genre inspiration rather than reproducing a specific work.
- Preserve the bilingual project identity and the existing visual language.

## Code style

- Use plain HTML, CSS, and JavaScript unless a larger architectural change is agreed upon.
- Prefer clear function names over abbreviations.
- Keep browser APIs progressive and avoid introducing a build requirement for the playable game.
- Do not commit secrets, personal save data, or generated credentials.
